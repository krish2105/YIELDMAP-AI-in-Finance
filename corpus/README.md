# Reference corpus

Public reference material the Ask feature and the memo writer cite. Each file carries its source
and the date it was written down, so a citation always points at a fixed text.

Where a document could not be retrieved from its publisher — `centralbank.ae` refuses automated
clients, and Dubai Pulse refuses them entirely — the file states the position in general terms and
marks the specific figures as unverified rather than asserting numbers that were not checked. The
ingest job replaces these with the archived originals once it can reach them.

Every fact a memo states must trace to one of these files or to a SQL query. Nothing in this
directory is invented; where a rule's detail is not established, the file says so instead of
filling the gap.
